In the rapidly expanding landscape of digital financial transactions, credit card fraud poses an increasingly complex and severe threat to global economic security. This project aimed to design and implement a multi-architecture machine learning platform. Our project is designed for real-time transaction scoring and fraud detection. To address the challenges of extreme class imbalance and high-dimensional features, the synthetic minority over-sampling technique (\gls{smote}) was applied on stratified, group-aware training splits, preventing data leakage and enhancing classification robustness. The system evaluates seven diverse architectures, leading to a custom hybrid Random Forest (\gls{rf}) and Recurrent Neural Network (\gls{rnn}) ensemble. This hybrid model successfully combines static feature space mappings with temporal transaction sequence analysis. The final system was integrated with a high-throughput, low-latency \gls{api} server using FastAPI and a premium, interactive web interface using Streamlit, featuring online local explanation trees using \gls{shap} values. The hybrid model achieved superior classification results, demonstrating the effectiveness of combining sequence modeling with tree-based ensembles for reliable and explainable fraud detection in financial pipelines.
